# 00. PRODUCT CONTEXT

> Status: **VALIDATED / DECIDED**
> Phase 0 の調査・議論で確定した前提。実装都合で書き換えない。

## サービス名

**肉体副業**

## 主要ペルソナ [VALIDATED]

30代独身男女を中心としたデスクワーカー。

典型像:

- 平日は PC / Slack / Excel を使うデスクワーク
- 休日も YouTube / Instagram / Netflix / スマートフォンを見ているうちに時間が終わる

## 提供したい選択肢

休日に PC / スマートフォンから離れて、

- 身体を使う
- 普段と違うことをする
- 必要なら報酬も得る

そういう仕事・アルバイト・ボランティア・地域活動を発見できる **編集メディア**。

## このサービスで「ない」もの

- 地方創生サイトではない
- 農業専門サイトではない
- 求人媒体を作ること自体が目的ではない

場所より **「普段のデスクワークと反対側にある体験・仕事」** を重要視する。

## BRAND [VALIDATED]

主要コピー:

```
休日にスマホ6時間。それ、休めてる？
心が疲れたら、身体を働かせ。

平日は、頭で稼ぐ。
週末は、身体で稼ぐ。

PC閉じて、汗かいて、
ついでにお金ももらう。

筋肉は、すべてを解決する。
週末、肉体副業。
```

ブランドは少し尖っていてよい。ただし以下は行わない:

- 個人攻撃
- 職業差別
- 属性攻撃
- 差別表現
- 社会問題への便乗炎上

炎上を目的にしない。しかし無難な wellness メディアにも寄せない。

## BRAND LAYER と FACT LAYER [DECIDED]

**非常に重要。この2層を混同しない。**

| Layer | 対象 | トーン |
| --- | --- | --- |
| Brand Layer | TOP / カテゴリ入口 / SNS / 記事リード | 尖っていてよい |
| Fact Layer | 案件情報（Listing 詳細の事実表示） | 正確で真面目 |

例:

- Brand Layer: 「土曜の予定が『草刈り』になる週末、なかなかない。」
- Fact Layer:
  ```
  9/19
  9:00–12:00
  神奈川県平塚市
  草刈り・稲架づくり
  初心者可
  最終確認：9/13
  情報元：公式ページ
  ```

## 実装上の帰結

- Fact Layer に表示する値は、必ず Source に存在した事実のみ。
- Brand Layer のコピーは `app/` 側の静的テキスト、または人間が書いた `editorial_note` にのみ存在する。
- `listings` テーブルの fact カラムに編集コピーを混ぜない。
